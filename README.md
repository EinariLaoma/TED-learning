# TED 精读计划

每周一篇 TED 主题精读的可安装网页 App（PWA）：点词查义、整句语法解析、记忆复习、每周两次考试、听说跟读、连续学习奖励，以及 PDF / Excel 导出。

**打开：** https://einarilaoma.github.io/TED-learning/

- iPhone / iPad：用 Safari 打开 → 分享 →「添加到主屏幕」
- Windows / Mac：用 Chrome 或 Edge 打开 → 地址栏右侧「安装」

学习记录只保存在你自己的设备上，本仓库里只有 App 文件。词典数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）。精读文是围绕对应 TED 演讲主题撰写的原创文本，不是演讲原稿。
