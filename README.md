# TED 精读计划

可安装的英语精读 App（PWA）：每周一场 TED 演讲，导入全文后分部分精读；点词查义（离线词典约 6 万词）、整句语法解析、记忆库复习、每周两次考试、现场原声逐句跟听、跟读对比、连续学习奖励，以及 PDF / Excel 导出。

**打开：** https://einarilaoma.github.io/TED-learning/

- iPhone / iPad：用 Safari 打开 → 分享 →「添加到主屏幕」
- Windows / Mac：用 Chrome 或 Edge 打开 → 地址栏右侧「安装」

**内容说明：** 本仓库不包含任何 TED 演讲讲稿或音频。App 内每篇只附一段约 250 词的原创导读；完整讲稿由使用者自己从 TED 官网复制后导入，音频由使用者自行选择文件导入。导入的内容和学习记录只保存在使用者自己的设备上。

词典数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT），句法分析使用 [compromise](https://github.com/spencermountain/compromise)（MIT）。
